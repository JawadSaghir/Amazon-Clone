# User Journeys

## Discovery

1. Shopper lands on the storefront.
2. Featured shelves and category chips expose database products.
3. Search filters products by title, brand, category, and tags.
4. Shopper sorts by relevance, price, rating, or deals.
5. Product detail page shows gallery, shipping, seller, reviews, and related products.

## Cart And Checkout

1. Shopper adds product to cart from listing or detail, or clicks `Buy now` to add the item and go straight to checkout.
2. Cart persists locally for guests.
3. Checkout asks guests to sign in.
4. Customer confirms address and coupon.
5. Server calculates final order totals.
6. Server saves a demo order in MongoDB.
7. Customer receives a success view and can inspect order history.

## Customer Dashboard

- Orders: statuses, line items, totals.
- Addresses: saved delivery profiles.
- Wishlist: saved products.
- Profile: name, email, phone.
- Notifications: account and delivery updates.
- Payments: demo payment explanation.
- Security: password and session controls.

## Admin Console

- Analytics: revenue, order count, customer count, average order.
- Products: searchable inventory table.
- Orders: status board.
- Users: role and activity list.
